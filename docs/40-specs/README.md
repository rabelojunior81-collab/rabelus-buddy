Uma SPEC por unidade de trabalho (marco, fase ou sub-fase), em `NNNN-slug/SPEC.md`, com template em [`../30-governanca/templates/SPEC.md`](../30-governanca/templates/SPEC.md). Alteração de escopo gera nova revisão no mesmo arquivo, com a aprovada anterior preservada no histórico e citada no cabeçalho.
