# Política de segurança · Security policy

## Português

O Rabelus Buddy está na **Fase 0**: ainda não há versão publicada nem código executável de produto. Mesmo assim, relatos de segurança são bem-vindos, inclusive sobre as ferramentas em `scripts/` e sobre o desenho descrito na documentação.

**Não abra issue pública para vulnerabilidades.** Enquanto o repositório for privado, contate o mantenedor de forma privada pelo perfil [@rabelojunior81-collab](https://github.com/rabelojunior81-collab). Quando o repositório se tornar público, o canal será o *Private vulnerability reporting* do GitHub (aba **Security**).

Inclua: o que é afetado, como reproduzir, impacto esperado e, se tiver, sugestão de correção. Responderemos assim que possível; não há SLA formal num projeto sem receita, e diremos isso com honestidade em cada caso.

Segredos nunca devem entrar no repositório. Se encontrar um, avise em privado.

## English

Rabelus Buddy is in **Phase 0**: there is no released version or runnable product code yet. Security reports are still welcome, including about the tools in `scripts/` and the design described in the docs.

**Do not open public issues for vulnerabilities.** While the repository is private, contact the maintainer privately through [@rabelojunior81-collab](https://github.com/rabelojunior81-collab). Once public, the channel will be GitHub *Private vulnerability reporting* (**Security** tab).

Include what is affected, how to reproduce it, expected impact and, if you have one, a suggested fix. There is no formal SLA in an unfunded project; we will be honest about timing in each case.

Secrets must never enter the repository. If you find one, report it privately.
